# 从安装到第一次使用

## 一次配置，日常直接打开

准备 Obsidian 桌面版、一个自己的库，以及 Python 3.12+。目前实机验证环境是 Windows，Python 路径应指向真正的 `python.exe`，其同目录须存在 `pythonw.exe`，不要填写应用商店别名。

在 PowerShell 执行一次（将路径替换为自己的 Python）：

```powershell
& "C:/Python312/python.exe" -m pip install "PyYAML>=6,<7"
```

从 [最新发布](https://github.com/LeoAI1988/yl-knowledge-workbench/releases/latest) 下载插件 ZIP，解压得到 `yl-knowledge-workbench`。不要把 GitHub 自动生成的 Source code 当作安装包。

将整个文件夹放到 `<你的库>/.obsidian/plugins/`，必须包含 `backend/`。重开 Obsidian，在第三方插件中启用「知识工作台」。

进入插件设置，填 Python 路径。助手名称、头像路径可选；已有知识库配置一般留空，插件会为当前库生成独立配置。点击「应用并打开」。以后点侧栏网络图标，或命令面板搜索「打开知识工作台」。

Windows 的后台进程不依赖终端。关掉安装终端不影响使用；电脑重启后打开插件会再启动。强制结束后台 Python 会中断服务，插件可重连。关闭页面或禁用插件不会立即停止共享后台。

## 先用演示库认识界面

下载源码，将 `examples/demo-vault` 复制到独立文件夹，用 Obsidian「打开文件夹作为仓库」，再安装插件。它包含虚构笔记、知识卡、表达和作品，没有作者私人资料。

想同时看预置选题/对话示例，参照 [开发文档](development.md) 运行演示脚本。预置内容明确标记为演示，不代表模型效果或流量实测。

## 再接自己的知识

1. 普通 Markdown 自动显示在「原始资料库」。
2. 已有笔记属性加 `type: OPI` 和 `domains: [你的领域]`，点「刷新知识视图」后可从知识卡进入。
3. 用 `[[笔记名]]` 连接两张已标类型的卡，点击其中一张，再点「查看关联」。同名笔记有歧义时不猜测，可改用库内相对路径。
4. `type: expression` 收录表达，正文保留原话；用双向链接指回知识卡。`type: work` 收录作品，可加 `platform`、`date`、`status`。
5. 「选题工坊」保存一个念头。没有模型也能保存；需增强或写作时再连接 Codex。

## 连接模型

在电脑安装/启动 Codex 并登录自己的账号。`codex` 应在 PATH 上；Windows 同时支持探测 Codex 桌面的常见安装目录。在插件「Codex 模型 ID」填账号可用的 ID，默认 `gpt-6-astra`。项目不赠送模型额度。

点击「应用并打开」，在工作台设置里「测试连接」。成功后可问答、增强选题和生成初稿。修改模型需等当前任务结束。不要把密钥写进笔记、Issue 或截图。

## 升级

先备份库与运行目录，关闭 Obsidian；若后台有生成任务先等它完成。结束属于这个插件的后台服务后再升级，避免旧进程继续运行旧代码。

解压新版本后，可运行附带的校验安装器：

```powershell
python ./yl-knowledge-workbench/install.py --vault "D:/MyVault" --dry-run
python ./yl-knowledge-workbench/install.py --vault "D:/MyVault" --upgrade
```

安装器校验包内清单，升级前备份已登记文件，保留 `data.json`、库内资料和用户目录中的配置/对话。核心被手动修改或出现未登记文件时拒绝覆盖；先备份并人工处理。旧 0.2 本地试用包清单不完整，需人工备份后迁移，不能直接按新版升级校验。

## 常见问题

**打开一直等待？** 检查 Python 路径、pythonw 和 PyYAML 是否在同一环境。详情在运行目录 `plugin-server.log`；提交问题前去掉路径、正文和账号信息。

**只有资料，没有知识卡？** 普通笔记默认不是知识原子，添加类型属性或使用 YL 完成蒸馏。领域为空进入待归类。

**没有历史播放量？** 通用适配器目前不导入平台指标。历史卡需要已有 YL 数据格式，缺失不能当作零。

**读取很慢？** 普通适配器扫描 Markdown 检测变化；大型库建议排除备份/生成目录。未对所有规模作性能保证。

**如何卸载？** 备份，关闭工作台/Obsidian，等任务完成后结束对应 Python 后台，再移除该插件文件夹。库内灵感、草稿及用户目录中的配置/对话不会自动删除。完全移除时只处理自己的对应库运行目录。
